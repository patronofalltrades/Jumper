Blink an LED

Complete

Wire GPIO 23 to an LED through a 220 Ω resistor, then run the LED's short leg back to GND.

The ESP32 is wide. Its pins sit in rows b and i, and the board body covers c to h, so each pin gets one free hole: a on top, j below. Hover any hole to see everything it's connected to.
